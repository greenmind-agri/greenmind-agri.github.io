Features

拆開來看，它是怎麼走完一輪的

這一頁把 Greenmind 自走車分成硬體、軟體與整體架構三層來說明。 以下規格為目前原型的設計配置，仍在開發與調整中。

Hardware

自走車硬體

要在真實田區裡走完一輪，車子得先撐得住地形。底盤、感測與動力這三件事， 決定了它能走多遠、走多穩、以及走的時候知不知道自己在哪。

  • 定位 GPS / RTK 定位模組，用於判斷車體在田區中的絕對位置。
  • 姿態 IMU 慣性測量單元，補足傾斜、轉向與顛簸時的姿態資訊。
  • 避障 超音波搭配視覺避障，處理田埂、支架與突發障礙物。
  • 底盤 四輪獨立驅動、可調懸吊，因應不平整的土面與壟溝。
  • 動力 鋰電池為主，搭配太陽能輔助充電以延長出勤時間。

Software

控制軟體

軟體要解決的問題很單純：讓操作的人隨時知道車在哪、接下來要往哪走， 以及這一輪巡完之後留下了什麼。

  • 路徑規劃 壟間往返路徑規劃（Boustrophedon）：走到一行盡頭即轉向下一行，覆蓋整個田區。
  • 操控模式 手動與自動雙模式切換，遇到需要人為介入的狀況可立即接手。
  • 即時監控 感測數據儀表板，把位置、姿態與環境數據集中在同一個畫面。
  • 資料回傳 雲端記錄與軌跡回放，讓每一次巡田都能事後重看與比對。

Architecture

從感測到操控，資料怎麼流

自走車上的每一次判斷，都是這四層依序跑完的結果。

  1. Step 01

    感測層

    GPS / RTK、IMU、超音波與視覺鏡頭同時取得位置、姿態與周遭環境資料。

  2. Step 02

    決策層

    融合感測結果，比對既定的壟間路徑，判斷該直行、轉向，還是先避開障礙。

  3. Step 03

    控制層

    把決策轉成四輪的實際動作：轉速、轉向與速度調整，讓車貼著路徑走。

  4. Step 04

    雲端 / 操控端

    影像、軌跡與感測數據回傳，操作者即時查看，也保留下來供事後回放比對。
